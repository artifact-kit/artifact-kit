# Artifact Kit

pnpm workspace for packages published under the `@artifact-kit` npm scope.

## Packages

- `@artifact-kit/pptxgenjs` in `packages/pptxgenjs`

## Common Commands

```bash
pnpm install
pnpm --filter @artifact-kit/pptxgenjs build
pnpm --filter @artifact-kit/pptxgenjs publish --access public
```
